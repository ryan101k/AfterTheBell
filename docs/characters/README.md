# 히로인 정본 인덱스

총 16명을 다섯 갈래로 관리한다. 인물 추가나 대사 수정 전에는 해당 그룹 문서의 결핍·말투·금지선을 먼저 확인한다.

| 갈래 | 인물 | 핵심 관계 | 정본 |
|---|---|---|---|
| 위험한 3인 | 윤새라·강유진·한채린 | 생활 침투·구원 독점·사적 굴복 | [`CHARACTER_BIBLE.md`](../../CHARACTER_BIBLE.md) |
| 자유인 3인 | 채원·유나·소희 | 붙잡지 않되 사라지지 않는 관계 | [`FREEDOM_TRIO.md`](./FREEDOM_TRIO.md) |
| 소꿉친구 5인 | 예린·보라·서연·나영·미래 | 선의로 위장된 분산형 통제 | [`CHILDHOOD_FIVE.md`](./CHILDHOOD_FIVE.md) |
| 사업 4인 | 박지수·한이슬·차서윤·오혜린 | 고용·지분·비밀과 애정의 분리 | [`BUSINESS_QUARTET.md`](./BUSINESS_QUARTET.md) |
| 독립 | 나래 | 정답을 대신 고르지 않는 신뢰 | [`NARAE.md`](./NARAE.md) |

은호의 비공개 가족 배경, 아버지 회사의 악명, 새라 사건에서 강유진이 맡는 법적 역할은 [`EUNHO_BACKGROUND.md`](./EUNHO_BACKGROUND.md)를 정본으로 사용한다.

은호의 과거를 아는 범위와 주인공 책임을 지적하는 현재 역할, 나래에게 대면 이후 서서히 생기는 관심은 [`SIWOO.md`](./SIWOO.md)를 정본으로 사용한다.

세계관 연결은 [`STORY_ORIGIN_BRIDGE.md`](./STORY_ORIGIN_BRIDGE.md)를 따른다. 주식게임 원형의 장부·차명계좌·기업 사건을 유지하되 랜덤 세력전은 사용하지 않는다.

전 장에 걸친 배경 인물·세력은 다음을 정본으로 사용한다. 은호의 아버지는 [`FATHER.md`](./FATHER.md)(위험과 선택지를 함께 지우는 회색 세력), 백야·태양캐피탈·자금망 등 외부 압박 세력은 [`ANTAGONISTS.md`](./ANTAGONISTS.md). 두 문서 모두 "외부 세력은 촉매이지 관계 파국의 단독 범인이 아니다"라는 금지선을 공유한다.

## 집착 강도의 방향

강도는 폭력 수치가 아니라 은호의 선택권을 얼마나 넓고 자연스럽게 침범하는지로 판단한다.

1. 자유인 3인: 자기 자리를 먼저 지우는 방향
2. 나래·사업 4인: 전문 권한과 사적 관계가 섞이는 방향
3. 위험한 3인: 한 사람이 한 영역을 노골적으로 독점하는 방향
4. 소꿉친구 5인: 다섯이 삶 전체의 권한을 분산 장악하는 방향

소꿉친구 5인이 가장 위험하지만, 더 잔혹한 행동을 하기 때문이 아니라 각자의 개입이 정상적인 돌봄과 추억처럼 보이고 서로의 사각지대를 메우기 때문이다.
