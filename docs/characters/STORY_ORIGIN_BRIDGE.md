# 주식게임 원형을 새 서사로 잇는 기준

새 작품은 주식 시뮬레이션이 아니지만, 원형을 지워 버리지는 않는다. 주식은 반복 플레이 시스템이 아니라 은호의 과거, 현재 사건, 나래와 사업 4인조를 연결하는 증거가 된다.

## 고정 사건

1. 생활경제연구회는 졸업 직전 모의투자 대회에 참가했다.
2. 대회 후원사의 페이퍼컴퍼니가 차명계좌로 주문을 조작했다.
3. 미래가 복제한 투자 계정과 다섯에게 나뉜 관리자 권한 때문에 외부 세력이 침입할 문이 생겼다.
4. 은호는 주문 조작의 원본 장부 일부를 가지고 있었지만 관계 파국 뒤 확인하지 않고 숨었다.
5. 현재 시장에서 같은 체결 간격과 주문 습관이 다시 나타난다.
6. 나래는 패턴을 읽는 법과 합법적인 신고 절차를 제공한다.
7. 윤새라는 같은 세력 때문에 거래처와 작업실을 잃었고 우회 송금 기록을 기억한다.
8. 강유진은 피해 자금과 개인정보 침해를 수사한다.
9. 한채린 계열 경호사의 하청망에서 차명계좌와 피해자 동선 매입 기록이 발견된다.
10. 사업 4인조는 유통·콘텐츠·계약·돌봄 현장에서 같은 자금망이 사람을 압박한 흔적을 각자 발견한다.

## `세력`의 새 의미

- 군대처럼 인원을 모아 다른 세력을 공격하는 시스템은 사용하지 않는다.
- `세력`은 은호 편에 선 사람들의 느슨한 협력망을 뜻한다.
- 시우는 보안과 원본 복구, 나래는 금융 해석과 신고, 유진은 수사, 채린은 기업 내부 정리, 새라는 피해 기록, 사업 4인조는 현장 증언을 맡는다.
- 갈등은 특정 기업·페이퍼컴퍼니·책임자를 상대로 한 증거 보존, 공개, 소송, 내부 고발과 안전 확보로 진행한다.
- 상대가 공격하는 이유는 랭킹이나 랜덤 이벤트가 아니라 장부 회수, 증거 인멸, 증인 압박이다.

## 돈과 사업의 역할

- 은호는 방 안에서 소규모 투자와 분석 의뢰로 생계를 유지할 수 있지만 매일 매수·매도하는 게임 화면은 만들지 않는다.
- 투자 결과는 인물의 신뢰를 올리는 선물이 아니라 은호가 자기 판단과 책임을 되찾는 과정이다.
- 사업은 네 사람을 고용해 숫자를 키우는 기능이 아니라, 조작 사건으로 피해를 본 현장을 복구하는 선택에서 시작한다.
- 돈으로 주거·법률·치료 문제를 해결할 수는 있지만 사람의 동의와 관계 정리는 살 수 없다.

## 장별 연결

| 장 | 시장 원형의 사용 |
|---|---|
| 프롤로그 | 폐장 시각, 은호의 방, 모의투자 장부의 잔상 |
| 윤새라 장 | 파산한 작업실과 우회 송금 기록 |
| 강유진 장 | 피해 자금, 개인정보 매입, 합법 수사 |
| 한채린 장 | 계열 경호사와 하청 페이퍼컴퍼니 |
| 나래 장 | 현재 시장에서 반복된 주문 패턴 분석 |
| 자유인 3인 장 | 공항·광고·공연 업계에서 들린 공개 정보와 소문 |
| 사업 4인 장 | 네 현장의 계약·정산·노동 기록 |
| 소꿉친구 장 | 모의투자 계정 침입 경로와 다섯의 관리자 권한 원본 |
| 최종장 | 증거 공개 또는 은폐, 각 인물의 책임 인정 |

## 금지선

- 이유 없이 나타나는 랜덤 습격과 조직 전쟁을 쓰지 않는다.
- 주가를 움직여 악당을 파산시키는 것으로 법적·관계적 책임을 대신하지 않는다.
- 금융 용어를 많이 쓰는 것으로 개연성을 증명하려 하지 않는다.
- 외부 세력을 모든 관계 파국의 단독 범인으로 만들어 소꿉친구와 은호의 책임을 지우지 않는다.
