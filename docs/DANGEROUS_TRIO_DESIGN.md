# 《폐장 후, 우리》 — 광기 3인 루트 설계안

> 정본 문서. 구현 파일(`src/passages/10-prologue` · `20-chapter1` · `30-chapter2` · `40-chapter3` · `45-dangerous-solo`)의 as-built 구조를 기준으로 한다. 인물 정본은 [`CHARACTER_BIBLE.md`](../CHARACTER_BIBLE.md), 전체 줄기는 [`STORY_OUTLINE.md`](../STORY_OUTLINE.md).

## 0. 로그라인 & 위치

주식 시뮬레이션 게임에서 스토리만 가져온 관계 중심 VN의 **첫 번째 앤솔로지 루트**. 은둔한 주인공 최은호에게 서로 얼굴도 모르는 세 여자가 각자 다른 문으로 들어오고, 셋의 "필요받고 싶은 방식"이 각기 다른 광기로 자란다. 챕터 진행: **광기 3인 → 자유인 3인 → 사업 4인 → 소꿉친구 5인**.

## 1. 중심 질문

> 필요한 사람이 되고 싶은 세 여자와, 선택의 책임을 미루고 싶은 주인공이, **보호와 통제의 차이**를 배울 수 있는가.

핵심 명제: *"선택하지 않는 것도 선택이다."* 은호의 회피가 감금을, 대면이 퇴로를 만든다 — 이게 엔딩 분기 자체로 증명된다.

## 2. 주인공 · 최은호

- 서술: 은호 1인칭 과거형. 말투는 짧고 평범하게.
- 결핍: 자기 선택 때문에 누군가 무너졌다는 죄책감 → 결정을 미루면 책임도 없다는 잘못된 믿음.
- 위험성: 상대가 의존할수록 안심한다. 나쁜 결말에서 은호는 피해자가 아니라 **세 광기의 공동 설계자**다("네 번째 사람의 광기").
- 성장축 `$playerPattern` = { face(대면) / delegate(위임) / avoid(회피) }. 선택마다 누적.
- 성장의 기준: `괜찮아`가 아니라 `지금은 대답 못 해`, 그리고 **좋아하는 사람에게도 직접 싫다고 말하는 것**.
- 숨긴 배경: 은호는 "그 집"(재력·재단·사교계) 출신이지만 몇 년째 이름을 감추고 산다. 이 세계를 아는 사람은 채린 하나뿐 — 그러나 **왜 도망쳤는지, 무슨 일이 있었는지는 아무도 모른다**(소꿉친구 편 반전 여력, §10).

## 3. 세 히로인 코어 (겹치면 안 되는 축)

| | 윤새라 | 강유진 | 한채린 |
|---|---|---|---|
| 직업 | 프리랜서 일러스트레이터 | 경찰(생활안전계) | 백야그룹 전략실 이사 |
| 결핍 | 쓸모없어지면 버려진다는 공포 | 사건이 끝나면 나도 필요 없어진다는 공허 | 돈·이름을 내려놓으면 아무도 안 남는다는 믿음 |
| **핵심 욕망** | 은호의 **생활**이 된다 | **글러먹은(망가진) 사람을 챙긴다** | 겉은 도도, **져도 버려지지 않을 굴복** |
| 사랑 방식 | 식사·귀가·열쇠 등 사소한 일상에 스며듦 | 기록·동행·안전 확인 | 자리·기회·계약·시선을 몰아줌 |
| **위험 방식** | 기다림→확인→**추적→생활 장악** | 보호를 빌미로 연락·거처·위험 판단을 대신함, **회복 뒤 관계에서 밀려날까 불안** | 공개적으로 장식품 취급, 사적으로 도발해 **명령을 훔침** |
| 각성 신호 | 비밀 복사열쇠, 분단위 동선 메모, 은호 물건을 자기 집에 몰래 이식 | 무단 긴급보호 등록, 복사열쇠를 보호신청으로 키움 | 사교회 뺨 이후 "그날처럼 해 봐요", 건물 매입으로 "꺾이고도 안 떠나는지" 확인 |
| 좋은 방향 | `알고 있었어요` → `물어봐도 돼요?` | `하지 마세요` → `걱정돼요, 그래도 결정은 은호가` | 도발로 훔치지 않고 **중단권을 쥐여준 채 직접 부탁** |
| 대사 톤 유지 | 초반 사과 많고 흐림 | 존댓말·확인형, 감정 드러날 때 짧아짐 | 존/반말 섞어 거리 흔듦, 진심일 때만 장식 사라짐 |

**핵심: 셋은 각자 은호의 하루를 "기록/장악"하려 하지만 방향이 다르다.** 새라=사적 침투, 유진=제도적 권한, 채린=값·굴복. 트리오 루트에서는 셋의 광기가 **연쇄**한다(새라 침투 → 유진 보호 → 채린 매입).

## 4. 시스템 (선택 3계층 + 수치 2종)

### 관계도 `$dangerousAffection.{sera,yujin,chaerin}` (0~100)
- 미시 선택으로 누적. 임계값 **80** 이상 + 경로 ≠ distance → `romanceOpen` 성립.
- 인물별 획득 곡선(의도된 비대칭):
  - 새라: 여러 +10/+8 누적형 + "선"에서 +40
  - 유진: +10/+12/+8 누적 + "선"에서 +65
  - 채린: 등장이 늦어 미시 적음, "선"에서 +85 몰빵
- distance 선택: +10~20만 주고 경로를 닫음.

### 리스크 `$dangerousSolo.{sera,yujin,chaerin}Risk` (감금 판정)
- 시작값 = (해당 "선"이 `indulge`면 1, 아니면 0).
- solo 루트 내 방종 선택마다 +1.
- **solo 상호구원(true)** 조건: `Risk ≤ 1 && 관계도 ≥ 80`. 아니면 **감금(captive)**.

### 선택 3계층
1. **미시 선택**(+8/+10): 대부분 "좋음의 정도" 차이 = 관계도 조정. *(개선 여지: §11 #1 — 방종형 미시선택에 risk 소량 연결 검토)*
2. **"선" 선택**(각 인물 1회, boundary / indulge / distance): `$chapter2.{sera,yujin,chaerin}Path` 결정 → 관계 개방 + solo 엔딩 성향.
3. **경로 선택**(2장 말·3장): solo / trio / none / 아버지 등 대분기.

## 5. 루트 아키텍처

```
프롤로그
 ├ memoryStance(책임/피해) ····· 회상 톤, playerPattern
 ├ 시우: 게임 파티 참가 ········· $routeUnlocks.freedom (자유인 전제조건)
 └ 복도 소리 → 문 여부
      ├ 문 연다 ─────────────→ 1장
      ├ (freedom만) 외면 ─────→ [PROLOGUE END · 화면 안의 사람들]
      └ 둘 다 외면 ──────────→ [EARLY END · 닫힌 방]

1장 (이름을 묻지 않은 열나흘): 새라 동거 + 유진(복지확인) 유입
2장 (돌아갈 주소): 새라 작업실 불법퇴거 사건을 축으로 3인 개별 루트
   ├ 새라 "선" → seraPath / +40
   ├ 유진 "선" → yujinPath / +65
   ├ 채린 유입(자선경매·정체 인지·사교회 뺨) → 채린 "선" → chaerinPath / +85
   ├ 나래(아버지) 지름길 = [BAD · father_captive]
   └ 조정실 수렴: 셋이 한 번도 대면 안 하고 흔적만 남김
2장 말 라우팅 (사건 뒤에 남은 사람들):
   romanceOpen.X = (Path ≠ distance) && (관계도 ≥ 80)
      ├ 1명만 open → 해당 solo 루트(45-dangerous-solo)
      ├ 3명 다 open → 3장(트리오 하렘)
      └ 아무도 안 함 → [NORMAL · none]

3장 (세 번의 고백 → 네 사람이 돌아갈 곳): 트리오 하렘
   셋이 처음 대면 → 각자 금지선 서명 → 광기 연쇄 재발 → 최종 선택
      ├ 책임을 각자 이름으로 → [TRUE · harem_true]
      └ 한집에 전부 맡김 → [BAD · harem_captive]

45-dangerous-solo: 새라S / 유진Y / 채린C 개별 순애 루트
   각 Risk 판정 → [SOLO TRUE] / [SOLO CAPTIVE]
```

## 6. 아웃컴 & 엔딩 맵 (`$dangerousOutcome`)

| 값 | 도달 | 유형 | 감금 | 자유인 |
|---|---|---|---|---|
| `unresolved` | 초기값 | — | — | — |
| `father_captive` | 2장 · 아버지의 손 | BAD | ● 아버지에게 삶을 넘김 | locked |
| `none` | 2장 · 아직 먼 계절 | NORMAL | — | **romance** |
| `harem_true` | 3장 · 돌아갈 곳이 네 군데 | TRUE | ✕ 각자 퇴로 있음 | **romance** |
| `harem_captive` | 3장 · 잠긴 네 번째 자리 | BAD | ● 나갈 수 없는 집 | locked |
| `solo_true_sera` | 3S · 임시가 아닌 주소 | SOLO TRUE | ✕ | **friend** |
| `solo_captive_sera` | 3S · 서로의 감금 | SOLO BAD | ● 서로의 감금 | locked |
| `solo_true_yujin` | 3Y · 사건 없는 내일 | SOLO TRUE | ✕ | **friend** |
| `solo_captive_yujin` | 3Y · 안전가옥 | SOLO BAD | ● 안전가옥 | locked |
| `solo_true_chaerin` | 3C · 내려놓은 왕관 | SOLO TRUE | ✕ | **friend** |
| `solo_captive_chaerin` | 3C · 황금감옥 | SOLO BAD | ● 황금감옥 | locked |

**설계 원칙:** 감금 엔딩은 각 인물(또는 은호)의 통제 방식을 그대로 반영한다 — 서로의 감금(새라)/안전가옥(유진)/황금감옥(채린)/잠긴 네번째 자리(하렘)/가장 빠른 해결(아버지).

## 7. 자유인 3인 게이트 (다음 챕터 이월)

`4장 · 다음 접속`에서 `$freedomMode` 결정:

```
!routeUnlocks.freedom              → locked
$dangerousOutcome == harem_true    → romance
$dangerousOutcome == none          → romance
$dangerousOutcome startsWith solo_true_ → friend
그 외(모든 감금)                   → locked
```

- **romance**: 하렘 성공 or 아무하고도 안 이어짐 → 자유인 연애 루트 개방.
- **friend**: 순애 → 자유인 만나되 친구.
- **locked**: 감금/아버지 or 프롤로그에서 게임 미참가 → 자유인 없음.
- 자유인 챕터는 이전 관계 공개(`$freedom.disclosedExisting`)에 반응한다 — 하렘이면 "세 명과 만난다"를 밝히는 자리가 생김.

## 8. 챕터별 비트 시트 (요약)

- **프롤로그**: 폐장 → 생활경제연구회 회상(memoryStance) → 아버지 → 시우/게임(freedom) → 복도 울음 → 문. *과거의 다섯·보호 계획·아버지를 씨앗으로만.*
- **1장**: 하룻밤 → 사흘 → 열나흘 동거. 새라의 "안심과 감시는 처음엔 같은 모양". 유진은 복지확인으로 유입. *은호가 새라를 핑계로 문턱을 다시 밟는다(상호구원 복선).*
- **2장**: 작업실 불법퇴거·저작권 강요. 새라(비밀 열쇠·추적) / 유진(무단 긴급보호) / 채린(정체 인지·공개 뺨·사적 굴복) 각성. 나래의 아버지 지름길(배드). 조정실에서 **대면 없이** 수렴. 은호가 "다시 하나의 통제망"이 될 위험을 자각.
- **3장**: 셋이 처음 대면 → 공동계약서를 세 장으로 찢어 **각자 금지선** → 광기 연쇄 재발(침투→보호→매입) → 은호가 자기 광기를 명명 → 네 개의 주소(true) / 잠긴 자리(captive).
- **solo(45)**: 각 인물과 단둘. 각자의 위험을 반복 시험(Risk) → 상호구원/감금.

## 9. 작성 금지선 (CHARACTER_BIBLE 준수 확인)

- 새라를 처음부터 노골적 스토커로만 쓰지 않는다(열나흘은 순정, 광기는 누적).
- 유진을 회복 자체에 실망하는 악인으로 쓰지 않는다(자기 욕망에 스스로 놀라는 비극으로).
- 채린의 지배↔굴복을 장면 편의로 뒤집지 않는다(공적 오만 유지, 사적 굴복 갈증).
- 폭력·감시·통제를 호감 상승의 즉각 보상으로 쓰지 않는다(뺨=신뢰 균열로 명시).
- 시스템 용어(호감도/해금/루트/수치)를 본문 대사·서술에 노출하지 않는다.

## 10. 다음 챕터로의 이월 (미스터리 여력)

- **소꿉친구 편 반전 카드(보존됨)**: "은호가 부자다"는 이미 소진. 그러나 **① 다섯 사람이 실제로 한 일(보호 계획 메커니즘·신입 축출) ② 왜·어떻게 무너졌나 ③ 은호 본인의 공모 정도 ④ 나래의 진짜 역할과 아버지가 지금 원하는 것**은 그대로 남아 있다. 채린의 대사 "당신이 왜 그 이름을 그렇게 싫어하는지 듣고 싶어요"가 이 여력을 본문에 못 박아 둔다.
- **아버지/나래**: father_captive 외에도 나래는 반복 등장 가능한 독립 히로인. 아버지의 목적은 "필요한 것만 보내고 무엇을 내줬는지 묻지 않는" 통제로만 제시.
- **자유인 3인**은 광기 3인의 대비군(건강한 다자관계). freedomMode가 이전 결말을 물려받는다.

## 11. 남은 개선 포인트 (우선순위)

1. **미시선택의 무게(핵심)**: +8/+10이 대부분 "좋음의 정도"라 결과가 같음. 방종형 미시선택 2~3개에 기존 `*Risk += 1`을 소량 연결하면 초반 성향이 감금 쪽으로 누적 → 선택에 무게. 관계도 게이팅(80)은 유지.
2. **2장 밀도**: 세 회사·보험 절차 구간(갈라진 세 회사~원작자의 이름) 1~2패시지 압축.
3. **트리오 도식**: "한 명이 선 넘음→명명" 반복 비트 일부를 라이벌 시점/사건 겹침으로 변주.
4. **정체 반전**: §10대로 소꿉친구 편을 "부자"가 아니라 "사건·책임"으로 설계(무편집, 설계 원칙).
